# caddy

Caddy with [`caddy-docker-proxy`](https://github.com/lucaslorentz/caddy-docker-proxy), rebuilt on every Caddy release.

```sh
docker pull ghcr.io/r3fuze/caddy:latest
```

Built for my own use — the plugin set may change without notice, and version tags are
re-pushed when it does. If you depend on this image, pin a digest
(`ghcr.io/r3fuze/caddy@sha256:…`) or fork the repo.
